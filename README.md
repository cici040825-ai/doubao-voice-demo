# 轻轻聊 · Doubao Voice Demo

面向手机的 AI 语音 / 视频通话交互原型。以浅色、粉紫蓝紫流动视觉与圆形通话操作呈现自然对话；未使用豆包品牌资产。

> 当前检出原本只有 README，没有第一版源代码。本次直接在原仓库补齐以下演示，不能据此声称对第一版实现完成了回归。所有语音、画面识别与导航均为本地模拟，不接入真实 AI、麦克风、摄像头或定位。

## 运行

无需安装依赖或构建，需要 Python 3：

```bash
cd /workspace/doubao-voice-demo
python3 -m http.server 4173 --bind 0.0.0.0
```

在本地运行时用浏览器打开 `http://localhost:4173`。也可直接打开 `index.html`。没有外部字体、图片或 CDN 依赖。云环境需通过所在平台提供的端口访问能力查看。

## 功能与展示路径

- **Listening**：流动、呼吸感视觉与“我在听”。“模拟用户说话”增强波动；“自然停顿 3 秒”降低动态并保持 Listening，不因短暂停顿结束。“说完了”仅为外侧课堂演示触发器，进入 Understanding 后自动回答。
- **Understanding**：视觉收拢、放慢节奏。面板的 Understanding 可保持该状态；完整对话和商品识别流程自动进入 Speaking。
- **Speaking**：稳定输出动态、波形与逐字短字幕。回答完自动回到聆听。
- **Interrupt**：立即取消回答和字幕计时器，切换“听你说”；可接续新问题，或点“继续刚才的话题”恢复原任务。
- **Pause / Resume**：进入“我等你”，恢复时保留话题；若暂停前正在回答，会接续暂停位置附近的内容。
- **Walking**：放大状态中心、隐藏字幕与扬声器按钮。演示路线：Walking → 自然停顿 → Pause（路口等待）→ Resume（接着聊）。
- **Video**：模拟茶店画面；分别点伯爵茶、红茶、柠檬茶，可显示对应框选、推荐标签和回答。
- **Navigation**：模拟三个门，目标出口高亮、方向箭头与短指引同步出现。点“无法确认方向”后移除方向断言，显示“暂时无法确认”和补拍门牌提示。
- 底部提供扬声器、麦克风、挂断、更多；视频 / 导航增加摄像头。更多中可切换模式与暂停。支持麦克风关闭反馈、摄像头遮罩、挂断与重新通话。

## 文件

- `index.html`：手机界面、商品 / 门场景、外侧 Demo Controls。
- `style.css`：响应式布局、动态视觉、各状态形态、视频框选与导航覆盖层；支持系统减少动态偏好。
- `app.js`：状态、字幕及计时器管理、打断、暂停恢复、模式切换和商品定位。
